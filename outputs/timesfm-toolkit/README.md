# TimesFM Toolkit

Локальная сборка **Google TimesFM 2.0 (500M, PyTorch)** для прогнозирования временных рядов в финмоделях и макро-анализе. Заточена под **macOS Apple Silicon (M1–M4)**, использует MPS-ускорение.

## Что внутри

```
timesfm-toolkit/
├── install.sh          # Один скрипт: venv + torch + timesfm + прогрев весов
├── requirements.txt    # Закреплённые версии библиотек
├── forecast.py         # CLI: Excel-in → Excel-out с P10/P50/P90 и графиками
├── sample_data.xlsx    # Демоданные: SaaS-выручка (5 лет) + макро (EURUSD, CPI)
├── _make_sample.py     # Генератор демоданных (можно править под свои сценарии)
└── README.md
```

## Быстрый старт (3 шага)

### 1. Установка

```bash
cd timesfm-toolkit
chmod +x install.sh
./install.sh
```

Скрипт сделает:
1. Найдёт `python3.10` или `python3.11` (если нет — подскажет `brew install python@3.11`).
2. Создаст `venv/` рядом со скриптами.
3. Поставит PyTorch с MPS, TimesFM 1.3.0, pandas, openpyxl, xlsxwriter, matplotlib.
4. Прокеширует веса `google/timesfm-2.0-500m-pytorch` с HuggingFace (~1 ГБ, один раз).

Время первой установки: 5–10 минут на нормальном интернете.

### 2. Активация окружения

```bash
source venv/bin/activate
```

### 3. Первый прогноз — на демоданных

```bash
# Выручка (месячная, прогноз на 12 месяцев вперёд)
python forecast.py --input sample_data.xlsx --sheet Revenue --horizon 12 --freq M

# Макро ряды (дневные, прогноз на 90 дней)
python forecast.py --input sample_data.xlsx --sheet Macro --horizon 90 --freq D
```

Результат — два новых файла:
* `sample_data_forecast.xlsx` — листы **History**, **Forecast**, **History+Forecast**, **Charts**
* `sample_data_forecast_charts/` — PNG-графики по каждому ряду

## Формат своих данных

Excel-файл, один лист на «пачку» рядов одинаковой частоты. Структура:

| Date       | Mila_MRR | Side_revenue |
|------------|----------|--------------|
| 2020-01-01 | 1 024 000 | 156 000     |
| 2020-02-01 | 1 087 000 | 168 000     |
| ...        | ...      | ...          |

Правила:
* Колонка **Date** обязательна, формат — даты.
* Любое число дополнительных числовых колонок — каждая будет прогнозироваться отдельно.
* Минимум **8 точек истории** на ряд (рекомендую ≥ 36 для месячных, ≥ 200 для дневных).

## Что на выходе

Книга `..._forecast.xlsx`:

| Лист              | Содержимое                                                              |
|-------------------|-------------------------------------------------------------------------|
| History           | Исходные данные как есть                                                |
| Forecast          | По каждому ряду: `<series>_P10`, `_P50`, `_P90`, `_mean`                |
| History+Forecast  | Склейка истории и медианного прогноза одной колонкой (для финмодели)    |
| Charts            | Встроенные PNG-графики «история + прогноз + P10–P90 коридор»            |

**P10 / P50 / P90 = bear / base / bull** — можно подключать напрямую в сценарный движок финмодели.

## Интеграция в финмодель (workflow)

1. В вашей операционной модели лист **Drivers** содержит исторические ряды (выручка, conversion, AOV и т.п.).
2. Раз в месяц/квартал выгружаете их в `inputs.xlsx`, прогоняете `forecast.py`.
3. В модели лист **Forecast_inputs** ссылается на `Forecast` через `=[forecast.xlsx]Forecast!B2` (или копируете значения).
4. Bull/Base/Bear колонки модели мапятся на `_P90/_P50/_P10`.
5. TimesFM даёт «нейтральную» точку отсчёта — поверх неё накладываете strategic adjustments (запуски продуктов, M&A, и т.п.).

## CLI-параметры

```
--input       путь к .xlsx с историей          (обязателен)
--sheet       имя листа                         (default: Sheet1)
--horizon     сколько периодов прогнозировать   (default: 12)
--freq        частота: D / W / M / Q / A        (default: M)
--output      путь для выходного .xlsx          (default: <input>_forecast.xlsx)
```

## Под капотом

* **Модель:** `google/timesfm-2.0-500m-pytorch` — 500M parameters, zero-shot foundation model.
* **Контекст:** до 512 точек истории учитывается.
* **Нативный горизонт:** 128 шагов; на больших horizon модель работает авторегрессивно.
* **Квантили:** TimesFM выдаёт mean + 9 квантилей (P10–P90); скрипт мапит P10/P50/P90 в bear/base/bull.
* **Устройство:** автоматически выбирается MPS (Apple Silicon) → CUDA → CPU.

## Траблшутинг

| Симптом                                                  | Что делать                                                          |
|----------------------------------------------------------|---------------------------------------------------------------------|
| `python3.10/3.11 not found`                              | `brew install python@3.11`, затем перезапустить `install.sh`        |
| `huggingface_hub` ругается на авторизацию                | Не нужен токен — модель публичная. Проверьте интернет и time-out.   |
| Очень долго на CPU                                       | Ожидаемо: 500M модель. Используйте MPS (Apple Silicon) или GPU.     |
| `ImportError: cannot import name 'TimesFm_2p0_500m_torch'` | TimesFM версии < 1.3.0. Сделайте `pip install -U timesfm==1.3.0`.   |
| Прогноз «прямой линией»                                  | Мало истории. Дайте хотя бы 36 точек для месячных, 200 для дневных. |

## Лицензии и оговорки

* TimesFM — Apache 2.0 (Google Research).
* Модель zero-shot: качество прогноза зависит от данных. Для критичных решений делайте бэктест на ваших исторических данных перед использованием в production.
* TimesFM — это **точечный/квантильный** прогноз, не вероятностное распределение в строгом смысле. Для риск-моделей используйте Monte-Carlo поверх.
